# CodeMaster — Production Launch

- Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml`.
- Deploy with HTTPS.
- Use Firebase Authentication for real accounts.
- Use Cloud Firestore Security Rules for user/admin data.
- Put the admin page behind real authentication and an admin role.
- Do not treat localStorage as secure authentication.
- Do not place private API keys/service-account credentials in frontend files.
- Add the real domain to Google Search Console and submit the sitemap.
- Keep third-party ad scripts out of the project.
- Test desktop, Android, iPhone, keyboard navigation, and slow networks.

This package is a strong static launch build. A genuinely secure multi-user admin/database system requires your Firebase project configuration and deployment credentials.
