# CodeMaster ProMax

نسخة ProMax من منصة CodeMaster العربية لتعلم البرمجة.

## التشغيل
افتح `index.html` بعد فك الضغط.

## لوحة الإدارة
افتح `admin.html` أو اضغط «لوحة الإدارة» أسفل الموقع.

لوحة الإدارة الحالية تعمل محليًا باستخدام LocalStorage وتوفر:
- نظرة عامة وإحصائيات
- إدارة المستخدمين
- إضافة وتعديل وحذف الدورات
- إضافة الدروس وروابط الفيديو
- سجل نشاط
- إعدادات المنصة
- تصدير نسخة احتياطية JSON

### مهم للنشر الحقيقي
هذه لوحة إدارة Frontend تجريبية وليست نظام صلاحيات آمنًا. عند نشر CodeMaster، اربطها بخادم وFirebase Authentication/Firestore، واستخدم صلاحيات Admin وقواعد Firestore مناسبة. Firebase يوصي باستخدام Authentication مع Security Rules لحماية بيانات Firestore، بينما إدارة المستخدمين بصلاحيات مرتفعة تتم عبر Admin SDK من بيئة خادم موثوقة.

المراجع الرسمية:
https://firebase.google.com/docs/auth/admin
https://firebase.google.com/docs/firestore/quickstart

## Launch checklist
- استبدل النصوص/الأرقام التجريبية بإحصائيات حقيقية قبل الإعلان.
- استخدم فيديو أصلي أو فيديو تملك حق استخدامه إذا أردت فيديو MP4 حقيقيًا.
- اختبر الموقع على الهاتف والكمبيوتر قبل النشر.
- انشر النسخة على استضافة HTTPS.
- أضف صورة Open Graph وأيقونة الموقع وحسابات التواصل.

## CodeMaster Launch Edition

هذه النسخة مهيأة كنسخة عرض وإطلاق أولي:
- صفحة رئيسية تسويقية مع مسار تعلم واضح.
- تجربة تعليمية عملية.
- قسم تحفيزي أصلي.
- مختبر وتمارين ومشاريع حسب مكونات النسخة.
- تحسينات SEO أساسية وبيانات مشاركة اجتماعية.
- تصميم متجاوب.

قبل الإعلان العام، انشر الموقع عبر HTTPS، واستبدل أي أرقام تجريبية بإحصائيات حقيقية، وتأكد من حقوق استخدام كل فيديو/صورة.
